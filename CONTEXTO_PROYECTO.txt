## QUÉ ES ESTE PROYECTO

Fashion Intelligence es una plataforma de detección de microtrends de moda.
Monitorea señales de internet (Google Trends, Reddit, webs de marcas) para detectar
tendencias emergentes antes de que lleguen al mainstream, calcula scores de oportunidad
comercial, y usa un LLM local (Ollama/Qwen3) para generar conceptos de producto concretos.

El primer experimento es sobre hoodies streetwear (hoodie_test_01):
11 keywords × 3 países (US, GB, CL) × 7 subreddits de Reddit.

---

## STACK TÉCNICO

- Backend: Laravel 11 (PHP 8.4) — API REST + Dashboard Livewire
- Data Engine: FastAPI (Python 3.11) — Scraping + NLP + Scoring + LLM
- Base de datos: PostgreSQL 18 (compartida entre Laravel y Python)
- LLM: Ollama local con modelo Qwen3:8b (gratuito, corre en la máquina)
- Queue: Laravel Queue con driver database
- Frontend: Livewire 3 + Tailwind CDN (MVP, sin compilación)

## DECISIONES DE DISEÑO IMPORTANTES

1. pgvector es OPCIONAL. El sistema lo detecta y lo salta si no está.
   Los embeddings de imágenes son una función futura.

2. Modo FREE por defecto. SCRAPE_MODE=FREE significa solo HTTP local
   y Reddit API oficial. Sin costo de scraping.

3. LLM local (Ollama). Privacy-first. Los datos nunca salen de la máquina.
   Fallback a spaCy si Ollama no está corriendo.

4. Sin npm/build en MVP. Tailwind via CDN para simplificar el setup.
   En producción se compila con npm run build.

5. Queue driver: database. Sin Redis necesario para empezar.
   php artisan queue:work procesa los jobs.

6. Los dos servicios (Laravel en :8000, Python en :8001) comparten
   la misma BD PostgreSQL. Se comunican via HTTP con un shared secret.
